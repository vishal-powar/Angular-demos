Angular App Anatomy

Key files and how Angular bootstraps and renders your app.

Important Files

  • package.json - npm scripts and dependency versions used by the app.
  • angular.json - workspace + build targets (assets, styles, optimization).
  • src/main.ts - application entry; bootstraps root component.
  • src/app/app.config.ts - providers (router, HTTP, interceptors).
  • src/app/app.routes.ts - routing table and lazy-loaded routes.
  • src/app/app.html - root app shell template (layout + outlet).
  • src/styles.scss - global styles applied to the whole app.

Bootstrap Flow Diagram

main.ts
  -> bootstrapApplication(App, appConfig)
    -> providers from app.config.ts
    -> router reads app.routes.ts
    -> renders app.html
    -> components render views + hooks run

Lifecycle Phases (High Level)

constructor
  -> ngOnChanges (inputs)
  -> ngOnInit
  -> ngDoCheck
  -> ngAfterContentInit / Checked
  -> ngAfterViewInit / Checked
  -> ngOnDestroy

Content Projection Diagram

Parent template
  -> <app-projector>
     [header slot]
     [default slot]
     [footer slot]

Projector template
  -> <ng-content select='[slot="header"]'>
  -> <ng-content>
  -> <ng-content select='[slot="footer"]'>

ng-content Variations

<app-projector>
  <h4 slot="header">Header</h4>
  <p>Default slot content</p>
  <div slot="footer">Footer</div>
</app-projector>

Use select to target elements by attribute or CSS selector. Default ng-content captures anything not matched by a selector.

ng-container Variations

<ng-container *ngIf="show">
  <h4>Grouped without extra DOM</h4>
  <p>Multiple nodes projected together.</p>
</ng-container>

ng-container groups nodes or hosts structural directives without rendering an extra element in the DOM.

ng-template Variations

<ng-template #note>
  <p>Template block</p>
</ng-template>

<ng-container [ngTemplateOutlet]="note"></ng-container>

<ng-container *ngIf="show; else note"></ng-container>

ng-template is a lazy block. Render it later with ngTemplateOutlet or use it as an else block.
